## 本版更新

- **模型选择与下载：** 内置 NanoDet；可从商城下载 YOLOX Nano 或 YOLOX-S。下载后核对大小、SHA-256 与本机兼容性，支持取消，下载不会自动启用。
- **目标勾选：** 人形、汽车、座椅（椅子/凳子）、桌子（餐桌类别）、猫、狗、宠物（猫和狗）、手机、沙发、床、电视、笔记本电脑、杯子、瓶子。共14个勾选项，对应13个 COCO 类别；猫狗与宠物重复勾选会去重。
- **彩框与中文标签：** 采用 FigJam 规则中的红、橙、深蓝、黄绿四色，按类别固定复用，标注“行人”“座椅”“猫”“狗”等实际类别。颜色不代表危险等级、身份或跟踪编号。中文字体随包离线附带。
- **复用事件与微信流程：** 检测到选中目标后，沿用连续命中、离开延时、冷却和单次事件上限；已完成的同一 MP4 用于网页播放、下载和微信取回。
- **微信指令补齐：** 支持“今日事件”，与“今天事件”相同；收到列表后可单独发送“播放第一条”或“播放第1条”。
- **模型与媒体边界修补：** 完善下载连接、取消和应用切换处理；录像首帧及尾段解码校验失败的片段不列为已完成录像。

## 算法商城六步上手

1. 在“摄像头”添加并启用自有 RTSP 摄像头，或刷新设备列表、选择内置 / USB 摄像头并添加启用；到“预览”确认画面在线。
2. 打开“算法商城”，选择内置 NanoDet，或先在 YOLOX Nano / YOLOX-S 卡片点击“下载”，等待模型就绪。包内只预置 NanoDet。
3. 勾选要识别的目标，取消不需要的目标；默认只勾选人形。勾选或下载本身不会切换算法。
4. 置信度先保留 **0.35**。杯子场景可先尝试 **YOLOX-S / 0.35**；本次实测成功，但 CPU 开销更高。调高数值可能增加漏检，调低可能增加误报。
5. 点击 **“应用模型和选中目标”**，核对“当前生效”显示的模型与目标。应用成功时会结束当前事件并保留片段，再使用新设置。
6. 在“设置 → 事件检测”确认 **“启用检测”** 打开，并确认该路摄像头 **“参与检测”** 打开。“设置 → 录像 → 事件录像显示目标框”默认开启。让选中目标进入镜头，再移开并等待事件结束，到“回放 → 事件录像”刷新查看。

## 微信查询与实时预览

在“设置 → 微信 ClawBot”勾选“启用”和“已登录时自动接消息”，保存后点击“扫码登录”，用本人微信扫码并确认。保持电脑开机、联网、程序运行且不休眠。

在微信**单独发送“今日事件”或“今天事件”**，收到列表后，再**单独发送“播放第一条”**；也可单独发“最新事件”。每条消息只发一个指令，列表15分钟内有效，只取回已完成且未超过设置大小上限的录像。事件录像查询无需安装 NetBird，也无需先开启实时预览。

实时预览沿用已有入口：同一 Wi-Fi 可开启局域网预览；外网查看需在电脑另装、登录 NetBird，为仅含本机的组授权 Peer Expose，并在 MiniNVR2 阅读转发说明后手动开启。手机不用安装额外应用，发送“预览1号”或“预览 摄像头名称”，点击“打开实时预览”。链接10分钟有效，请勿转发；电脑重启后需手动重开远程预览。NetBird 服务商能够处理经其代理转发的画面，免费档及使用限制由服务商决定。

## 识别与验证范围

2026-10-19，用户在本机电脑摄像头、YOLOX-S / 0.35 下确认 **“杯子有橙框和标签，移动时能跟随”**。同轮微信“今日事件 → 播放第一条”确认收到列表和视频且能播放，未单独确认本次杯子标签在手机的可读性。内置 NanoDet 在该杯子场景漏检，改用 YOLOX-S 后通过；不代表其他类别、镜头、光线或场景的准确率。

300项功能回归、补修后的38项微信定向检查及本次20项发布打包检查通过。最终同一 EXE 通过6项启动、10项模拟预览、4项模拟事件及8个真实模型公开样例场景检查；官方模型的直接与 CONNECT 代理下载、应用和重启检查通过，模型、中文字体及许可资源核验通过。公开样例与模拟微信不等同于家庭场景精度或真实手机收件。

需要了解的边界：

- 座椅暂不区分椅子与凳子；宠物只包含猫狗；桌子对应餐桌类别。
- 静止的选中物品也可能持续触发录像，直到事件时长上限。请只勾选需要的目标，并结合现场效果调整。
- 模型在本机 CPU 运行，不上传摄像头画面；YOLOX 需联网从固定官方来源下载。暂不支持任意模型网址、PT 文件或脚本导入。
- 只有新事件会添加分类框和标签，旧录像不会补框，原始预览及抽帧不增加这些框。开启画框会增加 CPU 开销，RTSP 录像分辨率可能降到共享预览大小（通常宽480像素）。
- 模型漏检、遮挡、小目标及处理超时可能造成缺框；失败时尽量保留原画面并提示。编码正常但收尾校验失败或超时的片段保留为待校验文件，暂不列入回放或微信查询。
- **V3 手机外网预览未重新实测（NOT_RETESTED）**；历史 v2.3.0 的合成画面手机结果不代替本版验收。其他电脑、其他账号、真实农场、多路长期运行及邮件投递仍待验证。
