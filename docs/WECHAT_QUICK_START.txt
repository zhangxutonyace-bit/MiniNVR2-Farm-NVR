MiniNVR2 微信 ClawBot 操作步骤
适用版本：Windows 64 位 v2.3.0

1. 启动程序

   完整解压 MiniNVR2-v2.3.0-windows-x64.zip，双击 MiniNVR2.exe。电脑浏览器会打开管理页面；没有自动打开时，在这台电脑上手动访问 http://localhost:8800 。

2. 启用微信功能

   打开“设置”，找到“微信 ClawBot”，勾选“启用”和“已登录时自动接消息”，再点击“保存设置”。

3. 用自己的微信扫码

   点击“扫码登录”，用手机微信扫描二维码，并在手机上确认。电脑页面显示“已登录，正在接收微信消息”后，即可使用。已登录时无需重复扫码。

4. 按需准备录像或当前画面

   查看事件：在电脑“回放”确认已有录制结束的事件录像，微信只能取回已经保存的录像。此功能不需要安装 NetBird，也不需要先开启局域网或远程预览。

   查看当前画面：在电脑“预览”确认摄像头画面在线，不需要先录制事件。按下方的外网或同一 Wi-Fi 步骤选择一种方式。

5. 接收一段事件录像（可选）

   在手机的“微信 ClawBot”聊天中，单独发送：

   最新事件

   程序会回传今天最近一段已完成的事件录像，收到后点开播放。

6. 查看事件列表并选择录像（可选）

   先发送“今天事件”，收到列表后，再单独发送“播放第1条”。还可以发送“昨天事件”“下一页”“上一页”。

使用提醒

每条消息只发送一个指令，例如先发“今天事件”，再发“播放第1条”，不要合并成“今天事件，播放第一条”。列表15分钟内有效，过期或程序重启后重新查询。

v2.4.0 本机修复版也支持“播放第一条”“播放第一段”“播放第1条事件”，均按本人最近查询的列表取片，不会另查今天所有摄像头。公开 v2.3.0 仍请使用“播放第1条”。

使用时，电脑需保持开机、联网，程序持续运行且不进入休眠。微信登录过期后，回到电脑页面重新扫码即可。

如果提示没有已完成事件，先在电脑“回放”中确认对应日期已有事件录像。正在录制或重封装中的片段需要结束后才能查看；视频超过设置中的大小上限时不会上传。

本机开发候选：事件录像人物框连续跟随（尚未发布）

1. 在电脑“设置 → 录像”查看“事件录像显示目标框”。默认打开，旧配置缺少这个字段时同样默认打开。可按现场背景选择红色、橙色或深蓝色，颜色不代表危险等级或识别置信度。

2. 点击“保存设置”，等待下一次新事件。当前正在录制的事件仍沿用开始时的开关与颜色。打开画框时，RTSP 与电脑摄像头均使用共享预览画面重新编码，RTSP 录像清晰度可能降为通常宽 480 像素，CPU 占用增加；关闭后恢复原录像方式。

3. 等事件结束，在网页“回放”中查看，再在微信发送“今天事件”，接着发送“播放第一条”。微信取回和网页回放共用同一个已完成 MP4，目标框直接在视频像素中，不依赖微信播放器绘制。旧录像不会补框。

4. 自动和 Haar 模式使用随程序附带的离线人物模型画框，图像跟踪会跟随移动，并减少小幅位置与大小抖动；事件触发规则仍沿用原设置。短暂漏检必须有当前画面支持，距上次人物确认最多保留 0.75 秒；人物离开或跟踪失败会清除。移动侦测模式只画移动区域。本功能未增加车辆、动物或身份识别；遮挡、远处小人或快速转身仍可能漏框，不能保证身份连续。

5. 画框无需联网或额外下载模型。若摄像头状态提示“事件目标框处理失败”，该事件已尽量保留原画面，部分帧可能缺框；单帧超过 0.5 秒处理预算也会继续保存原画面，不排队追赶历史帧。编码或首尾解码校验失败的片段不会进入已完成列表。编码正常但校验失败或超时时，会保留待校验文件并显示提示，供后续人工恢复，暂时不能回放或通过微信取回。

6. 新版跟随质量需用新的真实事件确认：人物走动、暂停、反向走、离开后，在电脑和微信查看框是否跟随及及时消失。合成视频测试只能验证跟踪和编码，不能代表真人识别准确率。

以上为本机开发候选的操作说明，公开下载的 v2.3.0 不包含此功能。合成素材和模拟 CDN 验证不能代替实际摄像头效果、目标准确率或真实微信手机收件播放验收。

手机移动网络或其他 Wi-Fi 查看当前画面

手机不用安装 NetBird 或额外 VPN 应用。电脑和摄像头仍连接原来的局域网。

1. 确认电脑“预览”页画面正常，微信显示“已登录，正在接收微信消息”。

2. 从 https://netbird.io/download 在电脑安装官方 NetBird，由你注册或登录，确认显示 Connected。安装会添加网络组件和后台服务。

3. 用同一个 NetBird 账号登录 https://app.netbird.io/ 。在 Access Control → Groups 建立仅含本机的组；在 Settings → Clients → Peer Expose 开启 Enable Peer Expose，仅允许该组并保存。

4. 在 MiniNVR2“设置 → 微信远程预览”勾选“微信优先使用远程预览链接”，点击“保存设置”。

5. 阅读转发说明，点击“同意转发并开启远程预览”，等待连接就绪。画面会经 NetBird 云端 HTTPS 代理转发，服务商可处理画面，确认接受后再开启。免费档及其限制由服务商决定，不承诺永久免费。

6. 手机关闭 Wi-Fi、使用移动数据，在微信单独发送“预览1号”或“预览 摄像头名称”，点击回复中的“打开实时预览”，确认画面持续更新。

电脑须持续开机、联网、运行程序且不休眠。每次程序重启后，要在电脑手动重新开启远程预览；不使用时点击“停止远程预览”。单路链接10分钟有效，请勿转发；到期重新发指令，点击最新回复。

完整配置和排查见同目录“微信远程预览-操作步骤.txt”。

查看同一 Wi-Fi 的当前画面

这项功能不需要已有事件录像。手机和电脑应连接同一个可信 Wi-Fi。

1. 先在电脑“预览”页确认摄像头画面正常，并按上面的第2、3步启用微信、扫码登录。

2. 先取消“微信优先使用远程预览链接”。在“设置 → 微信 ClawBot”找到“微信局域网预览（同一 Wi-Fi）”，勾选“启用局域网预览”。“本机 Wi-Fi IPv4”先留空，端口保留 8803。点击“保存设置”，确认预览状态显示“已开启”。

3. 在手机的微信 ClawBot 聊天中，单独发送：

   预览1号

   也可以发送“预览 摄像头名称”，把“摄像头名称”换成自己的设备名称。

4. 点击回复中的“打开实时预览”。画面约每秒更新一次，没有声音。链接有效期10分钟，请勿转发；到期或程序重启后，重新发指令取得新链接。

5. 手机打不开时，确认仍在同一个 Wi-Fi、没有改用移动数据，并避开有设备隔离的访客网络。如果自动选的地址不对，从 Windows 当前 Wi-Fi 属性中找到这台电脑的 IPv4，填入“本机 Wi-Fi IPv4”后保存，再取新链接。检查防火墙是否允许 MiniNVR2 在专用网络接收连接，不要关闭整个防火墙。

更详细的步骤和故障处理，见同目录的“微信局域网预览-操作步骤.txt”。

实测范围

2026-10-19，用户在最终 Windows v2.3.0 EXE 上使用手机移动数据，重新请求新链接后，确认能在微信内点击“打开实时预览”并看到持续更新的合成画面。本次仅覆盖一台电脑、一个扫码账号、一部手机与当前移动网络；真实摄像头、其他环境及长期稳定性未验收。

同一 Wi-Fi 预览的历史手机验收使用 v2.2.3：用户确认画面持续更新，未修改防火墙；该结果不代表所有设备和网络均兼容。

真实手机事件视频收件与播放是 v2.2.2 的历史验收：2026-10-18 使用“最新事件”收到并播放6秒合成测试画面。v2.3.0 通过了事件上传的本机模拟验收，本轮未重新完成真实手机事件视频播放验收。
