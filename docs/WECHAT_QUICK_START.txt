MiniNVR2 微信 ClawBot 操作步骤
适用版本：Windows 64 位 v2.2.3

1. 启动程序

   完整解压 MiniNVR2-v2.2.3-windows-x64.zip，双击 MiniNVR2.exe。电脑浏览器会打开管理页面；没有自动打开时，在这台电脑上手动访问 http://localhost:8800 。

2. 确认已有事件录像

   在“摄像头”中添加自己的设备，确认预览正常，并在“回放”中确认已有至少一段录制结束的事件录像。微信只能取回已经保存的录像。

3. 启用微信功能

   打开“设置”，找到“微信 ClawBot”，勾选“启用”和“已登录时自动接消息”，再点击“保存设置”。

4. 用自己的微信扫码

   点击“扫码登录”，用手机微信扫描二维码，并在手机上确认。电脑页面显示“已登录，正在接收微信消息”后，即可使用。

5. 先试着接收一段录像

   在手机的“微信 ClawBot”聊天中，单独发送：

   最新事件

   程序会回传今天最近一段已完成的事件录像，收到后点开播放。

6. 查看列表并选择录像

   先发送“今天事件”，收到列表后，再单独发送“播放第1条”。还可以发送“昨天事件”“下一页”“上一页”。

使用提醒

每条消息只发送一个指令，序号使用数字，例如“播放第1条”，不要写成“今天事件，播放第一条”。列表15分钟内有效，过期后重新查询。

使用时，电脑需保持开机、联网，程序持续运行且不进入休眠。微信登录过期后，回到电脑页面重新扫码即可。

如果提示没有已完成事件，先在电脑“回放”中确认对应日期已有事件录像。正在录制或重封装中的片段需要结束后才能查看；视频超过设置中的大小上限时不会上传。

查看同一 Wi-Fi 的当前画面

这项功能不需要已有事件录像。手机和电脑应连接同一个可信 Wi-Fi。

1. 先在电脑“预览”页确认摄像头画面正常，并按上面的第3、4步启用微信、扫码登录。

2. 在“设置 → 微信 ClawBot”找到“微信局域网预览（同一 Wi-Fi）”，勾选“启用局域网预览”。“本机 Wi-Fi IPv4”先留空，端口保留 8803。点击“保存设置”，确认预览状态显示“已开启”。

3. 在手机的微信 ClawBot 聊天中，单独发送：

   预览1号

   也可以发送“预览 摄像头名称”，把“摄像头名称”换成自己的设备名称。

4. 点击回复中的链接。画面约每秒更新一次，没有声音。链接有效期10分钟，请勿转发；到期或程序重启后，重新发指令取得新链接。

5. 手机打不开时，确认仍在同一个 Wi-Fi、没有改用移动数据，并避开有设备隔离的访客网络。如果自动选的地址不对，从 Windows 当前 Wi-Fi 属性中找到这台电脑的 IPv4，填入“本机 Wi-Fi IPv4”后保存，再取新链接。检查防火墙是否允许 MiniNVR2 在专用网络接收连接，不要关闭整个防火墙。

更详细的步骤和故障处理，见同目录的“微信局域网预览-操作步骤.txt”。

实测范围

2026-10-19，用户在最终 Windows v2.2.3 EXE 上通过真实微信打开预览链接，确认画面持续更新，未修改防火墙。本次仅覆盖一台电脑、一个扫码账号、一部手机和当时网络，不代表真实农场性能或所有设备兼容。
