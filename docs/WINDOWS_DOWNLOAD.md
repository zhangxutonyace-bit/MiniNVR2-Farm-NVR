# MiniNVR2 Windows 下载版先读说明

版本：2.2.3。目标系统：Windows 10 / Windows 11，64 位（x64）。

这是已经打包的桌面程序，包含 Python 运行环境、网页资源、OpenCV 检测模型和 FFmpeg，无需另外安装 Python。

解压后，同目录附有 `微信ClawBot-操作步骤.txt` 和 `微信局域网预览-操作步骤.txt`，用记事本打开即可查看扫码登录、事件录像查询和同一 Wi-Fi 当前画面的操作方法。

## 第一次使用

1. 下载 [MiniNVR2-v2.2.3-windows-x64.zip](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/releases/download/v2.2.3/MiniNVR2-v2.2.3-windows-x64.zip)。
2. 将整个压缩包完整解压到你有写入权限的文件夹。保留包内的说明和第三方许可文件，不要在压缩软件中直接运行，也不要放在需要管理员权限才能写入的程序目录。
3. 双击解压后的 `MiniNVR2.exe`。程序会在后台运行，并打开默认浏览器。如果浏览器没有自动打开，可以在这台电脑上手动访问 `http://localhost:8800`。
4. 首次启动没有摄像头。打开“摄像头”页面，先手动添加一台自己有权使用的 RTSP 摄像头，填写设备地址及本机所需账号信息。具体 RTSP 地址请以摄像头说明书为准。
5. 在“预览”中确认画面在线，再按现场光线、距离和画面变化调整检测设置。在“回放”中查看已完成的事件录像及按日合成的抽帧录像。当日抽帧通常到次日才合成。
6. 退出时，右键系统托盘中的 MiniNVR2 图标并选择“退出”，或使用网页“设置”中的“退出程序”。关闭浏览器标签页不会停止录像。

请先用一台摄像头验证，再逐步增加路数。可接路数、预览流畅度与录像效果取决于笔记本性能、设备编码、分辨率和网络状态。笔记本休眠、关机或程序退出后，无法继续录像；需要持续录像时，请在 Windows 设置中自行安排电源和休眠策略。

## 数据保存与访问

程序首次运行后会在 EXE 所在文件夹创建 `data` 目录，保存配置、日志和录像。若该目录不可写，程序会尝试用户目录下的 `NVRData`。下载包本身不附带配置、日志、真实录像、设备账号或邮箱凭据。

本机配置可能保存摄像头密码、邮箱授权码或微信会话资料，请按个人资料保管；不要把运行后生成的 `data` 或 `NVRData` 整包公开上传。更新版本前先正常退出并备份自己的数据；建议将新版解压到新文件夹，再按需要迁移数据。

管理页面默认只允许本机访问。如果浏览器提示无法连接，先确认程序仍在运行，且没有另一个 MiniNVR2 实例占用 8800 端口。程序不会自动扫描局域网，先使用手工添加摄像头的方式。

这是本地桌面工具。若需要从局域网访问完整管理页面，需先设置访问口令，再按仓库说明启动；远程管理应另行配置受控 VPN 或带 HTTPS 的访问层。下方的微信局域网预览是独立入口，只提供指定摄像头的当前画面。

## 微信 ClawBot 与邮件

启用并完成微信 ClawBot 接入后，可以通过微信查询指定摄像头、指定日期的事件列表，选择已结束的事件录像回传，也可以查询抽帧录像。这可以让笔记本在家里运行，人在外面通过熟悉的微信入口回顾画面。

在网页“设置”中启用微信并保存，点击“扫码登录”，用手机微信扫描并确认。保持程序运行和联网，然后在机器人聊天里每次单独发送一个指令。

微信事件指令：`今天事件`、`昨天事件 农场`、`事件 2026-10-18 1号` 查看列表；`最新事件` 直接取今天最近一段。列表每页10条，回复 `播放第2条`、`下一页`、`上一页` 选择和翻页，15分钟内有效且仅本人可用。只提供已结束的录像，超过配置的视频大小上限会提示而不上传。序号使用数字，例如先发 `今天事件`，收到列表后再单独发 `播放第1条`，不要合并成一句或使用“第一条”。

事件录像的真实手机收件与播放是 **v2.2.2 的历史验收**：2026-10-18 使用该版 EXE 扫码后发送 `最新事件`，手机收到并能播放6秒合成测试画面。v2.2.3 已通过事件上传的本机模拟验收，未重新完成真实手机事件视频收件与播放。邮件及微信默认关闭；需要时请由本人完成账号配置。

## 微信查看同一 Wi-Fi 的当前画面

无需先录制事件。手机和运行 MiniNVR2 的电脑应连接同一个可信 Wi-Fi，电脑保持开机，程序持续运行。

1. 在电脑“预览”页确认摄像头已有正常画面。
2. 在“设置 → 微信 ClawBot”启用微信并保存，点击“扫码登录”，用自己的手机微信扫码确认。状态应显示“已登录，正在接收微信消息”；已登录时无需重复扫码。
3. 在同一设置卡片的“微信局域网预览（同一 Wi-Fi）”勾选“启用局域网预览”。“本机 Wi-Fi IPv4”先留空自动选择，端口保留 `8803`，点击“保存设置”，确认预览状态为“已开启”。
4. 在手机的微信 ClawBot 聊天中，单独发送 `预览1号`；也可以发送 `预览 摄像头名称`，将“摄像头名称”换成自己的设备名称。
5. 点击返回的链接查看当前画面。页面约每秒刷新一次，无声音；每条链接只对应一台摄像头，有效期10分钟，请勿转发。

链接到期、程序重启或更新后，重新发预览指令取得新链接。关闭局域网预览或退出微信登录也会使旧链接失效。此链接不能进入管理页面，也不能下载录像。

打不开时，先确认手机仍使用同一个 Wi-Fi，没有切到移动数据；访客 Wi-Fi 的设备隔离可能阻止手机连接电脑。若自动地址不对，在 Windows“设置 → 网络和 Internet → Wi-Fi → 当前网络属性”找到这台电脑的 IPv4 地址，填入“本机 Wi-Fi IPv4”后保存，再请求新链接，不要填写手机或其他设备的地址。检查 Windows 防火墙是否允许 MiniNVR2 在专用网络接收连接；不要关闭整个防火墙，程序不会自动修改规则。机器人不回复时，检查微信登录及接消息状态、设置页错误提示；只有提示登录过期时才重新扫码。详细步骤见包内 `微信局域网预览-操作步骤.txt`。

2026-10-19，用户在上述最终 Windows v2.2.3 EXE 上，通过真实微信发送预览指令并点击链接，确认画面持续更新，未修改防火墙。实测仅覆盖本次电脑、扫码账号、手机与网络；没有独立核验设备型号或实际场景，不代表真实农场性能或其他网络、设备均兼容。

## 下载校验和第三方组件

Release 同时提供 [SHA256SUMS.txt](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/releases/download/v2.2.3/SHA256SUMS.txt)，可以用 Windows PowerShell 核对下载包：

```powershell
Get-FileHash .\MiniNVR2-v2.2.3-windows-x64.zip -Algorithm SHA256
```

结果应与 Release 提供的校验值一致。包内另有文件级的 `SHA256SUMS.txt` 和不含机器路径的 `RELEASE_MANIFEST.json`。通用说明文件名为 `先读我-使用说明.txt`。第三方许可原文保存在 `THIRD_PARTY_NOTICES`；源码来源与对应资料见 `THIRD_PARTY_SOURCES.md` 及 Release 中的第三方源码资产。v2.2.2、v2.2.1 下载版本保留。
