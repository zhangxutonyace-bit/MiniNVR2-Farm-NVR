# MiniNVR2 Windows 下载版先读说明

版本：2.2.1。目标系统：Windows 10 / Windows 11，64 位（x64）。

这是已经打包的桌面程序，包含 Python 运行环境、网页资源、OpenCV 检测模型和 FFmpeg，无需另外安装 Python。

## 第一次使用

1. 从本项目 GitHub Release 下载 `MiniNVR2-v2.2.1-windows-x64.zip`。
2. 将整个压缩包完整解压到你有写入权限的文件夹。保留包内的说明和第三方许可文件，不要在压缩软件中直接运行，也不要放在需要管理员权限才能写入的程序目录。
3. 双击解压后的 `MiniNVR2.exe`。程序会在后台运行，并打开默认浏览器，访问 `http://127.0.0.1:8800`。如果浏览器没有自动打开，可以手动访问这个地址。
4. 首次启动没有摄像头。打开“摄像头”页面，先手动添加一台自己有权使用的 RTSP 摄像头，填写设备地址及本机所需账号信息。具体 RTSP 地址请以摄像头说明书为准。
5. 在“预览”中确认画面在线，再按现场光线、距离和画面变化调整检测设置。在“回放”中查看已完成的事件录像及按日合成的抽帧录像。当日抽帧通常到次日才合成。
6. 退出时，右键系统托盘中的 MiniNVR2 图标并选择“退出”，或使用网页“设置”中的“退出程序”。关闭浏览器标签页不会停止录像。

请先用一台摄像头验证，再逐步增加路数。可接路数、预览流畅度与录像效果取决于笔记本性能、设备编码、分辨率和网络状态。笔记本休眠、关机或程序退出后，无法继续录像；需要持续录像时，请在 Windows 设置中自行安排电源和休眠策略。

## 数据保存与访问

程序首次运行后会在 EXE 所在文件夹创建 `data` 目录，保存配置、日志和录像。若该目录不可写，程序会尝试用户目录下的 `NVRData`。下载包本身不附带配置、日志、真实录像、设备账号或邮箱凭据。

本机配置可能保存摄像头密码、邮箱授权码或微信会话资料，请按个人资料保管；不要把运行后生成的 `data` 或 `NVRData` 整包公开上传。更新版本前先正常退出并备份自己的数据；建议将新版解压到新文件夹，再按需要迁移数据。

默认只允许本机访问。如果浏览器提示无法连接，先确认程序仍在运行，且没有另一个 MiniNVR2 实例占用 8800 端口。程序不会自动扫描局域网，先使用手工添加摄像头的方式。

这是本地桌面工具。若需要局域网访问，需先设置访问口令，再按仓库说明启动；远程访问应另行配置受控 VPN 或带 HTTPS 的访问层。

## 微信 ClawBot 与邮件

启用并完成微信 ClawBot 接入后，可以尝试通过微信查询指定摄像头、指定日期的抽帧录像。这可以让笔记本在家里运行，人在外面通过熟悉的微信入口回顾画面。

当前微信功能仍为实验模块，主要提供抽帧录像查询，微信端查询事件片段尚未接入。本轮没有验证真实账号扫码登录、上传或视频送达，也不承诺当前账号和协议兼容性。邮件及微信默认关闭；需要时请由本人完成账号配置并自行验证。

## 已有验证范围

此 EXE 在打包本机完成了 HTTP 启动、端口冲突、内置 FFmpeg 合成视频预览、网页退出和局域网口令要求检查。程序包核对了 EXE 字节及 SHA-256，并检查 ZIP 完整性。

Windows 10/11 x64 是发布目标，尚未在另一台没有开发环境的 Windows 电脑上验证；托盘菜单的人工点击、真实农场摄像头、检测准确率、多路长期运行和真实邮件/微信收发仍待验证。检测可能误报或漏报，请结合实际场景确认效果。

## 下载校验和第三方组件

Release 同时提供 `SHA256SUMS.txt`，可以用 Windows PowerShell 核对下载包：

```powershell
Get-FileHash .\MiniNVR2-v2.2.1-windows-x64.zip -Algorithm SHA256
```

结果应与 Release 提供的校验值一致。包内另有文件级的 `SHA256SUMS.txt` 和不含机器路径的 `RELEASE_MANIFEST.json`。第三方许可原文保存在 `THIRD_PARTY_NOTICES`；源码来源与对应资料见 `THIRD_PARTY_SOURCES.md` 及 Release 中的第三方源码资产。
