# 微信预览链接格式兼容验收

## Intent

**Problem:** 用户确认预览画面能从手机外网访问，但微信聊天中的网址不能直接点击，需要复制到浏览器。此前手机画面验收不能当作微信内直接点击的验收。

**Approach:** 只调整成功回复的文字排版，不改动 `#t=` 授权片段、10 分钟有效期、选路、权限、错误回复或消息收据。第一轮 Windows 候选版单次发送完整原始网址，通过 163 项离线检查及 EXE 启动/模拟预览检查；用户确认“网址仍不能点击”，因此不视为达成目标。第二轮临时源码诊断版通过现有文字接口单次发送 `[打开实时预览](原始网址)`，通过 164 项离线检查和源码进程的 10 项模拟预览检查，独立盲审未发现新增问题。公开协议没有网页卡片类型，部分 Markdown 支持也不证明链接一定可点击；第二轮手机结果仍待确认，正式 EXE 和 GitHub 未更新为该格式。
