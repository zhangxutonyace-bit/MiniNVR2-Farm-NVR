# 微信预览链接格式兼容验收

## Intent

**Problem:** 用户确认预览画面能从手机外网访问，但微信聊天中的网址不能直接点击，需要复制到浏览器。此前手机画面验收不能当作微信内直接点击的验收。

**Approach:** 只调整成功回复的文字排版，不改动 `#t=` 授权片段、10 分钟有效期、选路、权限、错误回复或消息收据。通过现有文字接口单次发送 `[打开实时预览](原始网址)`，通过 164 项离线检查、源码进程的 10 项模拟预览检查，独立盲审未发现新增问题。2026-10-19，用户在源码诊断版确认显式链接可点击且画面持续更新；重新打包并安装最终 Windows EXE 后，再次确认“能，点击后在微信内持续更新”。最终 EXE 通过 6 项启动、10 项模拟预览、4 项模拟事件检查；SHA-256 为 `1a91c7c89fb0a7747213bd208e6ea385f0ec20ce509976d73b2e5bb0dc770443`。本轮只验证合成动画、当前扫码账号、手机及移动网络；该格式随 v2.3.0 发布。

## Acceptance status (2026-10-19)

- 纯网址回复的 Windows 候选版：手机浏览器可查看画面，微信聊天内直接点击未通过。
- 显式“打开实时预览”链接的临时源码诊断版：用户确认微信内可点击，并能看到持续更新的合成画面。
- 最终 Windows EXE：已重新打包并安装，通过 6 项启动、10 项模拟预览、4 项模拟事件检查；用户重新获取新链接后确认微信内点击和画面持续更新。证据绑定同一 EXE，保存在忽略目录 `validation-local/live-wechat-clickable-exe-v2.3.0.json`。
- 当前只验证本机、该扫码账号、手机与移动网络，不包括真实摄像头、其他账号或网络、长期稳定性；发布版本为 v2.3.0。
