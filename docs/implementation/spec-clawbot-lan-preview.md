## Intent

**Problem:** 微信只能查询录像，无法从对话直接打开指定摄像头的当前画面。

**Approach:** 授权用户发“预览1号”或“预览 农场”，机器人返回短时单摄像头链接；手机在同一 Wi-Fi 点击后进入专用预览页。

## Boundaries & Constraints

**Always:** 保留微信本人/白名单及会话校验；独立局域网预览端口只提供单路只读画面；链接10分钟有效；每帧检查期限、摄像头启用及新鲜度；主管理端口和鉴权保持原规则。默认关闭，用户在设置明确开启。使用合成摄像头测试。

**Ask First:** 如需新增 Windows 防火墙规则，展示具体端口和专用网络范围；真实账号再次扫码由用户完成。

**Never:** 不做公网、VPN、隧道、路由器端口映射；不在链接放管理口令或 RTSP 地址；不自动添加真实摄像头或发送私人画面；不借预览权限访问管理接口和录像。

## I/O & Edge-Case Matrix

| 场景 | 输入/状态 | 结果 | 错误处理 |
| --- | --- | --- | --- |
| 指定摄像头 | 预览1号、预览 农场、预览 摄像头1 | 回复该路链接，URL单独占一行 | 未匹配时提示名称/序号，不扩大到全部 |
| 未指定 | 仅一路/多路摄像头 | 一路直接发；多路列出可选项 | 零路提示先添加 |
| 访问条件 | 未开启、无可用私网IPv4、端口冲突 | 不返回不可用链接 | 明确提示设置或网络状态 |
| 凭据 | 缺失、篡改、过期、另一摄像头 | 拒绝画面 | 手机提示回微信重新请求 |
| 摄像头状态 | 在线新帧/连接中/离线/陈旧/删除 | 新帧显示，其他清空旧图并说明 | 不把历史图片冒充直播 |
| 撤销 | 关闭预览、改地址/端口、退出或更换微信登录 | 旧链接立即失效 | 已打开页面停止刷新 |

## Design Notes

局域网服务与管理服务分离，默认端口8803。使用摄像头现有JPEG，避免额外编码；手机逐帧取图而非永久长连接，确保到期立即生效。链接密钥只在fragment与Authorization头中，不进入请求URL和访问日志。地址自动选本机出口，支持手填本机Wi-Fi IPv4；同一Wi-Fi也可能受访客隔离或防火墙影响，须分别记录证据。
