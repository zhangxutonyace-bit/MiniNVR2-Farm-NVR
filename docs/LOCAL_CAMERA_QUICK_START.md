# 电脑内置 / USB 摄像头操作步骤

适用：Windows x64 的 v2.4.0 及更新版本。[下载 v2.4.0 Windows 便携包](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/releases/download/v2.4.0/MiniNVR2-v2.4.0-windows-x64.zip)。

## 添加并预览

1. 启动程序，打开管理页面，进入“摄像头”。USB 摄像头先连接电脑。
2. 在“电脑摄像头”卡片点击“刷新设备列表”。这一步只读取设备名称，不打开镜头。
3. 选择内置或 USB 摄像头，填写方便识别的名称，例如“电脑摄像头”，点击“添加并启用”。这时才开始采集画面，不采集麦克风。同一设备只能添加一次；同名设备会分别列出。
4. 到“预览”查看画面。回到“摄像头”点击“停用”可释放镜头；删除或退出程序也会释放。关闭网页标签页不会退出程序。设备成功添加后，之后启动程序会重新连接已启用的设备。

## 沿用现有检测和事件录像

1. 在“设置”确认“人形检测 → 启用检测”打开，并确认这路摄像头的“识别人”开关打开。全局检测关闭时仍能预览和抽帧，但不会触发事件录像。
2. 检测模式、检测间隔、连续命中次数、离开延时和冷却沿用原有设置。电脑摄像头接入不改变事件检测算法；本版新增的离线人物模型只用于定位画框。事件检测仍可能漏检、误报，需结合现场光线、距离和背景验证。
3. 现有算法连续命中后自动开始事件录像；人员离开、达到离开延时后结束。检测关闭、设备停用或程序退出也会停止录像。达到原有单次事件时长上限时仍按原有规则收尾。
4. 在“回放”选择这路摄像头和“事件录像”，刷新后播放已结束的片段。正在编码的片段不列出；本机片段采用 H.264 MP4，清晰度跟随共享取流画面，和 RTSP 高清流直接封装的方式不同。

## 微信查看

沿用原来的 ClawBot 配置和本人授权：先发送“列表”确认序号，再单独发送“预览 电脑摄像头”，点击“打开实时预览”。预览需要已有的局域网或远程预览入口；只有同一 Wi-Fi 时按[局域网步骤](LAN_PREVIEW.md)设置，跨网段按[远程预览步骤](REMOTE_PREVIEW.md)设置。不要把带授权的链接转发给他人。

查看已结束事件时，单独发送“今天事件 电脑摄像头”，再根据返回列表发送“播放第一条”或“播放第1条”；也可发送“最新事件 电脑摄像头”。名称替换为自己保存的摄像头名称。每次只发一个指令，不会因添加本机摄像头而主动向微信推送画面。

“设置 → 录像”的“事件录像显示目标框”默认打开；自动 / Haar 模式使用离线人物定位加连续跟踪，移动模式只画移动区域。保存开关与颜色后，从下一次新事件生效；网页和微信回传的同一个 MP4 都会保留框。旧录像不会补框。打开画框会增加 CPU 占用，详见[下载使用说明](WINDOWS_DOWNLOAD.md#电脑摄像头与事件人物框)。

## 常见问题

- **列表为空：** 检查 USB 连接和驱动，稍后点击刷新。程序不会自动安装驱动或改系统权限。
- **连接中或无画面：** 先关闭相机、视频会议等占用镜头的软件，再检查 Windows“隐私和安全性 → 摄像头”中对桌面应用的访问权限。未开启权限时由本人调整。
- **拔出或换接口：** 程序会显示离线并按现有重试规则重连原设备，不会擅自换到其他镜头。USB 换接口或驱动变化导致设备标识改变时，刷新后删除旧条目、重新选择添加。
- **有画面但没有事件：** 先检查全局检测和该路“识别人”开关；确认片段已结束后再刷新回放。既有检测算法并不保证每次有人经过都会命中。
- **显示录像编码失败：** 检查磁盘空间和程序日志。本机事件录像需要编码，可能增加 CPU 占用；失败或未完成的片段不会发布为已完成录像。
