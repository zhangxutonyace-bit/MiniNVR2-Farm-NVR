# 电脑内置 / USB 摄像头操作步骤

适用：Windows x64 的 v3.1.0；电脑摄像头接入自 v2.4.0 提供。[下载 v3.1.0 Windows 便携包](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/releases/download/v3.1.0/MiniNVR2-v3.1.0-windows-x64.zip)。

## 添加并预览

1. 启动程序，打开管理页面，进入“摄像头”。USB 摄像头先连接电脑。
2. 在“电脑摄像头”卡片点击“刷新设备列表”。这一步只读取设备名称，不打开镜头。
3. 选择内置或 USB 摄像头，填写方便识别的名称，例如“电脑摄像头”，点击“添加并启用”。这时才开始采集画面，不采集麦克风。同一设备只能添加一次；同名设备会分别列出。
4. 到“预览”查看画面。回到“摄像头”点击“停用”可释放镜头；删除或退出程序也会释放。关闭网页标签页不会退出程序。设备成功添加后，之后启动程序会重新连接已启用的设备。

## V3 多目标事件

V3.1 可在“算法商城”应用一个模型与选中目标，检测到这些目标后沿用下方事件录像和微信查询流程。YOLOX 需先下载，下载不自动启用。V3.1 预览可实时显示类别彩框与中文标签，完成的事件 MP4 按录像开关添加固定类别色描边和中文标签，与商城勾选项前的色样一致；颜色不代表危险等级、身份或跟踪编号。尚未应用商城时保持旧版模式，以下人物触发说明仅描述旧模式。[算法商城操作步骤](ALGORITHM_STORE_QUICK_START.md)。

## 直接在预览中查看识别效果

在“算法商城”选模型、勾选目标并应用，再打开全局检测和本路“参与检测”。到“预览”保持“实时显示识别框和标签”勾选，目标进入镜头后就能看到类别彩框和中文标签，无需等事件结束。取消勾选可对比原画面，不改变录像设置。[实时预览完整步骤](LIVE_PREVIEW_DETECTION.md)。

2026-10-20，用户在本机 V3.1、YOLOX-S、杯子/瓶子选择的电脑摄像头预览中确认“彩框和标签能跟随，画面流畅”。这只覆盖本次电脑、镜头与设置，不代表其他目标、设备或手机预览均已验收。

## 沿用现有检测和事件录像

1. 在“设置”确认“事件检测 → 启用检测”（旧版称“人形检测”）打开，并确认这路摄像头的“参与检测”开关（旧版称“识别人”）打开。全局检测关闭时仍能预览和抽帧，但不会触发事件录像。
2. 检测模式、检测间隔、连续命中次数、离开延时和冷却沿用原有设置。电脑摄像头接入本身不改变事件检测算法；仅在自动 / Haar 等旧模式中，离线人物模型只用于定位画框。商城模式则用选中目标的语义检测结果触发录像，沿用原有连续命中和离开计时。事件检测仍可能漏检、误报，需结合现场光线、距离和背景验证。
3. 现有算法连续命中后自动开始事件录像；旧模式按人员判断，商城模式按选中目标判断，不再命中并达到离开延时后结束。检测关闭、设备停用或程序退出也会停止录像。达到原有单次事件时长上限时仍按原有规则收尾。
4. 在“回放”选择这路摄像头和“事件录像”，刷新后播放已结束的片段。正在编码的片段不列出；本机片段采用 H.264 MP4，清晰度跟随共享取流画面，和 RTSP 高清流直接封装的方式不同。

## 微信查看

沿用原来的 ClawBot 配置和本人授权：先发送“列表”确认序号，再单独发送“预览 电脑摄像头”，点击“打开实时预览”。预览需要已有的局域网或远程预览入口；只有同一 Wi-Fi 时按[局域网步骤](LAN_PREVIEW.md)设置，跨网段按[远程预览步骤](REMOTE_PREVIEW.md)设置。不要把带授权的链接转发给他人。

查看已结束事件时，单独发送“今天事件 电脑摄像头”（也支持“今日事件 电脑摄像头”），再根据返回列表发送“播放第一条”或“播放第1条”；也可发送“最新事件 电脑摄像头”。名称替换为自己保存的摄像头名称。每次只发一个指令，不会因添加本机摄像头而主动向微信推送画面。

“设置 → 录像”的“事件录像显示目标框”默认打开；商城模式使用固定类别色和中文标签，自动 / Haar 模式使用离线人物定位加连续跟踪，移动模式只画移动区域。保存后从下一次新事件生效；网页与微信共用同一个已完成 MP4。旧录像不会补框。打开画框会增加 CPU 占用，详见[下载使用说明](WINDOWS_DOWNLOAD.md#电脑摄像头与事件目标框)。

## 常见问题

- **列表为空：** 检查 USB 连接和驱动，稍后点击刷新。程序不会自动安装驱动或改系统权限。
- **连接中或无画面：** 先关闭相机、视频会议等占用镜头的软件，再检查 Windows“隐私和安全性 → 摄像头”中对桌面应用的访问权限。未开启权限时由本人调整。
- **拔出或换接口：** 程序会显示离线并按现有重试规则重连原设备，不会擅自换到其他镜头。USB 换接口或驱动变化导致设备标识改变时，刷新后删除旧条目、重新选择添加。
- **有画面但没有事件：** 先检查全局检测和该路“参与检测”开关（旧版称“识别人”）；确认片段已结束后再刷新回放。既有检测算法并不保证每次有人经过都会命中。
- **显示录像编码失败：** 检查磁盘空间和程序日志。本机事件录像需要编码，可能增加 CPU 占用；失败或未完成的片段不会发布为已完成录像。

## 当前证据
