## 主要修复

1. 补依赖锁定与安装入口，移除原机器 D 盘路径依赖，增加隔离的本机演示。
2. 固定包含 Haar 模型和分类器 API 的 OpenCV 4.12；避免原算法在 OpenCV 5 环境下失效。包说明参见 [OpenCV Python 4.12](https://pypi.org/project/opencv-python/4.12.0.88/)，当前兼容性以本机实测为依据。
3. 修复线程停止、初次连接超时、扫描取消后重试、检测开关与录像生命周期、事件回放和 Range 行为。
4. 默认仅本机，补齐 API/视频鉴权，隐藏凭据，限制摄像头 ID；邮件 TLS 失败时停止认证；微信仅对明确授权用户响应。
5. 修复 Windows 监听端口重复占用导致第二实例误报就绪；网页退出可以结束整个程序。
6. 原测试改为临时数据测试，防止测试覆盖配置或删除真实录像；构建清理不删除 `dist` 内用户数据。
