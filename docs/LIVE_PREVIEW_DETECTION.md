# V3.1 实时预览彩框与标签操作步骤

V3.1 在电脑“预览”中直接显示当前算法识别出的目标，以类别彩框和中文标签展示，并随目标移动连续跟随。

[下载 Windows 64 位便携包 v3.1.0](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/releases/download/v3.1.0/MiniNVR2-v3.1.0-windows-x64.zip)。完整解压后双击 `MiniNVR2.exe`，无需另装 Python 或 FFmpeg。没有自动打开页面时，在电脑访问 `http://127.0.0.1:8800`。

## 使用步骤

1. 启动新版程序，添加并启用摄像头，到“预览”确认画面在线。
2. 在“算法商城”选一个已就绪的模型，勾选需要识别的目标，点击“应用模型和选中目标”。仅下载、勾选还不会生效。
3. 确认“设置 → 事件检测 → 启用检测”打开，并确认该摄像头的“参与检测”打开。
4. 回到“预览”，保持“实时显示识别框和标签”勾选，即可查看检测到的目标、彩框和中文标签。该开关默认打开。
5. 想对比原始画面时，取消“实时显示识别框和标签”。它只影响当前电脑预览，不会修改录像的“事件录像显示目标框”设置。

杯子可以先用本机实测通过的 **YOLOX-S / 0.35**。首次需先在商城下载，等待模型就绪，再选中并应用；下载包只预置 NanoDet。其他物品按现场效果选择模型和目标。YOLOX-S 比轻量模型更消耗电脑资源，建议先用一路摄像头确认跟随和流畅度，再增加路数。

## 没有框或不流畅时

- **只有画面、没有框：** 核对商城“当前生效”的模型和目标；确认全局“启用检测”、该路“参与检测”和预览“实时显示识别框和标签”都已打开。只有识别到选中目标才画框。
- **杯子容易漏检：** 可尝试 YOLOX-S / 0.35，让完整杯身出现在镜头中，避免强逆光。模型仍可能漏检，切换模型不会给旧录像补框。
- **电脑负载较高：** 先减少摄像头路数、降低取流宽度，或试用轻量模型；参考摄像头状态提示判断。程序在处理跟不上时优先更新原画面，待处理恢复后再显示框。

## 显示规则

- 与商城的新事件录像采用同一套类别配色与中文标签，如红色“行人”、橙色“杯子”、深蓝色“猫”和黄绿色“狗”。类别颜色不代表危险等级或人物身份。
- 只有商城模式和检测都生效的摄像头才显示多目标识别框。旧自动、Haar、移动模式或关闭检测时仍显示原画面，预览页会提示启用方式。
- 短暂漏检时，会结合当前画面尝试继续跟随；目标离开、画面变化、摄像头重连或切换模型时，会清除不再匹配的框。识别本身仍可能受遮挡、光照、目标大小和模型能力影响。
- 处理跟不上时，优先保持画面更新并提示。不会为了留住框而停止预览画面，也不会无限积压等待处理的视频帧。
- 观看彩框预览时，会按需补充识别结果；多个观看窗口共用同一模型和结果。停止观看后，额外刷新会自动停止。录像仍按设置中的检测节奏和条件判定。
- 原始取流、按日抽帧与原有事件触发流程保留，预览框不会重复写进事件录像。

## 微信预览

既有微信预览链接也读取同一路识别预览。在微信发送“预览1号”或“预览 摄像头名称”，打开新返回的链接即可。权限和有效期沿用原设置；本功能不会自动开启局域网或外网入口。

微信预览仍沿用原来的约每秒刷新一次，电脑预览则跟随现有取流速度。电脑上的“实时显示识别框和标签”开关只影响当前电脑页面，不会改变微信页面。微信实际观看效果需在已配置的手机上另行确认。

## 本次实测范围

2026-10-20，用户在本机电脑摄像头、YOLOX-S / 0.35、杯子 / 瓶子选项下移动杯子，确认 **“彩框和标签能跟随，画面流畅”**。这是该电脑、镜头与设置的实时预览实测；不代表所有目标、光照、设备或多路长期运行的效果。V3.1 新增彩框在手机上的实际效果尚未由用户确认。
