# 实时预览识别框（3.1.0 本地候选）

本功能在电脑预览中显示当前算法识别出的目标，以类别彩框和中文标签展示。开发与测试记录见 `implementation/spec-live-preview-detection.md`；此文档不代表已经发布新的 GitHub Release。

## 使用步骤

1. 启动新版程序，添加并启用摄像头，到“预览”确认画面在线。
2. 在“算法商城”选一个已就绪的模型，勾选需要识别的目标，点击“应用模型和选中目标”。仅下载、勾选还不会生效。
3. 确认“设置 → 事件检测 → 启用检测”打开，并确认该摄像头的“参与检测”打开。
4. 回到“预览”，保持“实时显示识别框和标签”勾选，即可查看检测到的目标、彩框和中文标签。该开关默认打开。
5. 想对比原始画面时，取消“实时显示识别框和标签”。它只影响当前电脑预览，不会修改录像的“事件录像显示目标框”设置。

杯子可以先用此前实测通过的 YOLOX-S / 0.35；其他物品按现场效果选择模型和目标。YOLOX-S 比轻量模型更消耗电脑资源。首次使用先用一路摄像头，确认跟随和流畅度，再增加路数。

## 显示规则

- 与商城的新事件录像采用同一套类别配色与中文标签，如红色“行人”、橙色“杯子”、深蓝色“猫”和黄绿色“狗”。类别颜色不代表危险等级或人物身份。
- 只有商城模式和检测都生效的摄像头才显示多目标识别框。旧自动、Haar、移动模式或关闭检测时仍显示原画面，预览页会提示启用方式。
- 短暂漏检时，会结合当前画面尝试继续跟随；目标离开、画面变化、摄像头重连或切换模型时，会清除不再匹配的框。识别本身仍可能受遮挡、光照、目标大小和模型能力影响。
- 处理跟不上时，优先保持画面更新并提示。不会为了留住框而停止预览画面，也不会无限积压等待处理的视频帧。
- 观看彩框预览时，会按需补充识别结果；多个观看窗口共用同一模型和结果。停止观看后，额外刷新会自动停止。录像仍按设置中的检测节奏和条件判定。
- 原始取流、按日抽帧与原有事件触发流程保留，预览框不会重复写进事件录像。

## 微信预览

既有微信预览链接也读取同一路识别预览。在微信发送“预览1号”或“预览 摄像头名称”，打开新返回的链接即可。权限和有效期沿用原设置；本功能不会自动开启局域网或外网入口。

微信预览仍沿用原来的约每秒刷新一次，电脑预览则跟随现有取流速度。电脑上的“实时显示识别框和标签”开关只影响当前电脑页面，不会改变微信页面。微信实际观看效果需在已配置的手机上另行确认。
