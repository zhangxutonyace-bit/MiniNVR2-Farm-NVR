# 微信远程查看摄像头当前画面

适用于 v3.0.0；此功能自 v2.3.0 提供。手机可以使用移动网络或其他 Wi-Fi，**不用安装 NetBird 或 VPN 客户端**，在微信请求预览链接并点击 **“打开实时预览”** 查看。网络摄像头仍与电脑连接原来的局域网，也可预览已添加到平台的电脑内置 / USB 摄像头；电脑须保持开机、联网，MiniNVR2 持续运行。

2026-10-19 的微信内点击及持续更新手机实测使用 v2.3.0 最终 Windows EXE 和合成画面。V3 保留该逻辑并通过本机模拟预览检查；本轮手机外网预览未重新实测（NOT_RETESTED），历史手机结果和 V3 事件录像收件均不代替 V3 外网预览验收。

## 首次配置

1. 在电脑的 MiniNVR2“预览”页确认摄像头已有正常画面。在“设置 → 微信 ClawBot”启用微信、扫码登录，并确认正在接收消息。已经登录的用户无需重复扫码。
2. 在这台电脑上从 [NetBird 官网](https://netbird.io/download) 安装官方 Windows 客户端。安装可能需要 Windows 管理员确认，并会添加其网络组件；由你注册或登录自己的 NetBird 账号，确认客户端已连接。MiniNVR2 不会替你注册、安装或修改其账号设置。
3. 打开 [NetBird 控制台](https://app.netbird.io/)，使用与电脑客户端相同的 NetBird 账号登录。在 **Access Control → Groups** 建立仅包含这台电脑的组；然后进入 **Settings → Clients → Peer Expose**，开启 **Enable Peer Expose**，仅选择该组并保存。无需把手机加入 NetBird，也无需配置摄像头、管理端口或整个局域网的映射。
4. 回到 MiniNVR2“设置 → 微信远程预览”，勾选 **“微信优先使用远程预览链接”**，点击 **“保存设置”**。
5. 阅读界面中的转发说明，点击 **“同意转发并开启远程预览”**。等待状态显示连接就绪；未就绪时先按页面提示处理。
6. 在手机微信 ClawBot 聊天中，**单独发送 `预览1号`**，或发送 `预览 农场`（把“农场”替换成摄像头名称）。只有一路摄像头时，也可以只发送 `预览`。机器人返回 **“打开实时预览”**，直接点击该文字，在微信内查看画面。每次打开最新回复；链接有效期 10 分钟。如果旧版返回的纯网址不能点击，可复制完整网址到手机浏览器打开，不要删除其中的 `#t=` 及其后内容。

首次请关闭手机 Wi-Fi，用移动网络打开新链接，确认能看到持续更新的画面。这一步才能验证自己的外网环境实际可用。

## 日常使用与停止

- 画面约每秒刷新一次，无声音；页面切换到后台会暂停，回到页面恢复。它用于查看当前画面，事件录像仍使用“最新事件”等原有指令。
- 每条链接只允许查看指定的一台摄像头，有效期 10 分钟，请勿转发。收到后直接打开最新链接；到期、程序重启、微信身份变化或摄像头停用后，重新发送预览指令获取新链接。不要刷新已打开的旧页面来续期。
- 每次重新启动 MiniNVR2，都需要在电脑上手动开启远程预览；勾选项不会自动恢复远程连接。开启后的新链接可能与上次不同。
- 不需要远程查看时，点击 **“停止远程预览”**。程序会撤销旧链接并关闭本机画面入口。
- 如果想恢复原来的同 Wi-Fi 预览，取消 **“微信优先使用远程预览链接”** 并保存，再按[局域网预览步骤](LAN_PREVIEW.md)配置。选中远程模式但连接失败时，机器人会提示错误，不会偷偷改发局域网链接。

## 打不开时

| 提示或现象 | 处理方法 |
| --- | --- |
| 尚未安装 NetBird | 在电脑安装官网 Windows 客户端，并由你登录、连接；安装后刷新设置页。不要使用改名或来历不明的程序。 |
| 官方数字签名未通过 | 从 NetBird 官网重新安装；程序只使用官方安装位置的客户端，不接受任意可执行文件。 |
| 没有登录、未连接 | 先在电脑的 NetBird 客户端恢复连接，再回 MiniNVR2 重新开启远程预览。 |
| Permission Denied／需要 Peer Expose 权限 | 在 NetBird 控制台按首次配置第 3 步开启权限，并核对本机所在组。 |
| NetBird 阻止传入连接 | 查看该客户端的 Block Inbound Connections 设置；确认用途后由你调整再重试，不要关闭 Windows 整体防火墙。 |
| 客户端不支持命令、启动失败或连接超时 | 从官网下载更新；检查电脑联网和账号权限后重试。MiniNVR2 不会自动更改网络或防火墙规则。 |
| 微信没有回复 | 在电脑设置确认微信“已登录，正在接收消息”，查看文字回复错误提示；单独重发指令，不要把多个指令合成一句。 |
| 链接过期、无效或刚更新了程序 | 在微信重新发送预览指令，点击新链接。页面为减少密钥残留会移除地址栏里的链接密钥，直接刷新旧页面可能需要重新点击聊天链接。 |
| 摄像头离线或画面已中断 | 先检查电脑预览页和摄像头网络。手机页会停止显示中断的旧画面，不会把旧图当成实时画面。 |
| 电脑显示就绪，手机仍打不开 | 用手机浏览器交叉检查同一新链接，并检查移动网络或当前 Wi-Fi 是否限制访问。免费代理、运营商网络与微信内浏览器均可能影响可达性；本机测试成功不代表这些环境都可用。 |

## 转发方式与验证范围

MiniNVR2 只把一个独立、只读、带时限授权的摄像头预览入口交给 NetBird 转发。此入口不提供管理设置、录像下载、摄像头密码或局域网浏览权限；原管理页面仍在电脑上。

画面经 NetBird 云端 HTTPS 代理转发。**HTTPS 在服务商代理端终止，因此服务商能够处理转发内容。** 只有确认接受这种方式后才开启远程预览。拥有尚未过期链接的人也可能查看该路画面，请勿转发链接。

截至 2026-10-19，NetBird 公布的免费档面向个人和小团队，最多 5 名用户、100 台设备；Reverse Proxy 仍处于测试阶段。账号资格、功能、带宽与连接限制由服务商决定，后续可能变化，不能理解为永久免费的监控服务承诺。程序不会代为购买付费方案。

离线自动检查使用本机合成画面、真实的本机 HTTP 入口和假代理进程，验证程序的鉴权与启停行为。2026-10-19 的早期 Windows 候选版使用真实 NetBird 服务验收：公网 HTTPS 预览资源可达、未授权画面读取被拒绝、管理接口隔离共 10 项检查通过；用户关闭手机 Wi-Fi、使用移动网络，在微信发送 `预览 外网测试画面`，打开新链接并确认画面持续更新。素材为合成动画，手机未安装 NetBird 或 VPN 客户端。用户随后补充当时需将网址复制到浏览器；该早期结果证明手机外网预览可用，不证明微信聊天内直接点击或微信内置浏览器已通过验收。

公开 iLink 协议目前定义了文字与媒体消息，没有公开网页卡片类型。本程序通过文字消息发送显式链接 `[打开实时预览](完整网址)`，未改动预览密钥和权限。2026-10-19，用户先在源码诊断版确认“能点击，并在微信内看到持续更新画面”；重新打包、安装 v2.3.0 最终 Windows EXE 后，再次确认“能，点击后在微信内持续更新”。该历史 EXE 的 SHA-256 为 `1a91c7c89fb0a7747213bd208e6ea385f0ec20ce509976d73b2e5bb0dc770443`。两次素材均为合成动画，该版 EXE 的启动、模拟预览和事件回复检查也通过。相关公开实现见[腾讯协议](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md)、[文字发送器](https://github.com/Tencent/openclaw-weixin/blob/main/src/messaging/send.ts)和[部分 Markdown 支持记录](https://github.com/Tencent/openclaw-weixin/blob/main/CHANGELOG.zh_CN.md)。
