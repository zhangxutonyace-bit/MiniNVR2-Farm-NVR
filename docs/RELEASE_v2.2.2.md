本版补齐微信 ClawBot 事件录像查询，并提供重新打包的 Windows 64 位便携程序。

### 下载与运行

下载 [MiniNVR2-v2.2.2-windows-x64.zip](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/releases/download/v2.2.2/MiniNVR2-v2.2.2-windows-x64.zip)，无需安装 Python 或 FFmpeg。

更新前正常退出并备份原来的 `data` 数据目录。微信功能默认关闭，需要本人启用、扫码接入。

本版附第三方组件许可、来源资料和 `SHA256SUMS.txt`；使用的依赖版本与 v2.2.1 相同。

### 微信 ClawBot 配置与查看录像

1. **启动程序**

   完整解压下载包到可写文件夹，双击 `MiniNVR2.exe`。电脑浏览器会打开管理页面；没有自动打开时，在这台电脑上手动访问 `http://127.0.0.1:8800`。

2. **确认已有事件录像**

   在“摄像头”中添加自己的设备，确认预览正常，并在“回放”中确认已有至少一段录制结束的事件录像。微信只能取回已经保存的录像。

3. **启用微信功能**

   打开“设置”，找到“微信 ClawBot”，勾选“启用”和“已登录时自动接消息”，再点击“保存设置”。

4. **用自己的微信扫码**

   点击“扫码登录”，用手机微信扫描二维码，并在手机上确认。电脑页面显示“已登录，正在接收微信消息”后，即可使用。

5. **先试着接收一段录像**

   在手机的“微信 ClawBot”聊天中，单独发送 `最新事件`。程序会回传今天最近一段已完成的事件录像，收到后点开播放。

6. **查看列表并选择录像**

   先发送 `今天事件`，收到列表后，再单独发送 `播放第1条`。还可以发送 `昨天事件`、`下一页`、`上一页`；列表每页10条，翻页后序号保持不变。

**每条消息只发送一个指令，序号使用数字。** 例如先发 `今天事件`，收到列表后再发 `播放第1条`，不要写成 `今天事件，播放第一条`。列表按本人保存，15分钟内有效，过期后重新查询。

需要筛选时，可以发送 `昨天事件 农场` 或 `事件 2026-10-18 1号`，按日期、摄像头查找；`最新事件` 也可以加日期或摄像头。原有 `昨天 农场` 等抽帧录像命令继续可用。

使用时，电脑需保持开机、联网，程序持续运行且不进入休眠。微信登录过期后，回到电脑页面重新扫码即可。正在录制、重封装中的文件不提供，超出配置大小上限的文件不上传；仅登录所有者或明确允许的用户可以请求录像。
