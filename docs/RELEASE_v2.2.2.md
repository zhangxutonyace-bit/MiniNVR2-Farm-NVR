本版补齐微信 ClawBot 事件录像查询，并提供重新打包的 Windows 64 位便携程序。

### 微信查看事件录像

- 发 `今天事件`：查看今天已经结束的事件列表。
- 发 `昨天事件 农场` 或 `事件 2026-10-18 1号`：按日期、摄像头筛选。
- 回复 `播放第2条`：取回自己刚查到的列表中的第2段录像。
- 发 `下一页`、`上一页`：翻看列表，每页10条，序号保持不变。
- 发 `最新事件`：直接取回今天最近一段已结束录像，也可以加日期或摄像头。
- 原有 `昨天 农场` 等抽帧录像命令继续可用。

列表按本人保存，15分钟过期；正在录制、重封装中的文件不提供，超出配置大小上限的文件不上传。仅登录所有者或明确允许的用户可以请求录像。

### 下载与运行

下载 **MiniNVR2-v2.2.2-windows-x64.zip**，完整解压到可写文件夹，双击 `MiniNVR2.exe`，无需安装 Python 或 FFmpeg。程序默认打开 `http://127.0.0.1:8800`。

更新前正常退出并备份原来的 `data` 数据目录。微信功能仍默认关闭，需要本人启用、扫码接入；事件录像必须来自已经运行并保存录像的摄像头。

本版附第三方组件许可、来源资料和 `SHA256SUMS.txt`；使用的依赖版本与 v2.2.1 相同。
