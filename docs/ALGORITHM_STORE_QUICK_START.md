# V3.0 算法商城操作步骤

适用：MiniNVR2 3.0.0 Windows 版。[下载 Windows 便携包](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/releases/download/v3.0.0/MiniNVR2-v3.0.0-windows-x64.zip) · [Release 更新说明](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/releases/tag/v3.0.0)。完整解压后双击 `MiniNVR2.exe`，无需安装 Python；同目录也有本说明的 TXT 版本。

## 选择模型和目标

1. 启动程序，在“摄像头”添加并启用自己有权使用的网络摄像头或电脑内置 / USB 摄像头，到“预览”确认画面在线。
2. 打开“算法商城”。内置 NanoDet 无需下载；也可在 YOLOX Nano 或 YOLOX-S 卡片点击“下载”。下载会显示进度，支持取消。完成大小、SHA-256 和本地兼容性校验后才显示已就绪；下载失败、取消均不改变当前算法。
3. 选中一个模型，勾选目标，默认只勾选人形。支持人形、汽车、座椅（椅子/凳子）、桌子（餐桌类别）、猫、狗、宠物（猫和狗）、手机、沙发、床、电视、笔记本电脑、杯子、瓶子。一次模型推理同时识别勾选目标，不会为每个选项另运行一个模型。
4. 置信度默认 0.35。数值越高越严格，可能增加漏检；降低则可能增加误报。杯子场景可先尝试 YOLOX-S / 0.35，本次用户实测成功，但比轻量模型更消耗 CPU。先用一路摄像头验证，再决定是否增加路数。
5. 点击“应用模型和选中目标”。程序先检查模型，保存成功后结束当前事件并保留片段，再切换到新设置，避免同一片段混用算法。下载和勾选本身不会启用商城算法。
6. 在“设置 → 事件检测”确认“启用检测”打开，并确认摄像头的“参与检测”开关打开。原有检测间隔、连续命中次数、目标离开停录时间、冷却及单次事件上限继续生效。

## 查看事件和微信录像

选中目标连续命中后自动录像；不再检测到选中目标并达到离开延时后结束。打开“设置 → 录像 → 事件录像显示目标框”后，新事件 MP4 包含分类描边框和紧凑色底中文标签，例如“行人”“座椅”“猫”“狗”。只有标签底色填充，目标内部保持可见；标签靠近边缘时会调整位置。旧录像不会补框。预览和按日抽帧始终保持原画面。

每类固定使用下表颜色，与商城勾选项前的色样一致。四色来自 FigJam 的单模型多标签配色，稳定复用，不代表危险等级、身份或跟踪编号；不显示置信度分数。勾选宠物后只标注实际识别出的猫/狗。

| 中文标签 | 描边与标签底色 |
| --- | --- |
| 行人、手机、笔记本电脑 | 红色 `#F51616` |
| 汽车、座椅、沙发、杯子 | 橙色 `#E86D08` |
| 猫、床、瓶子 | 深蓝色 `#0931C0` |
| 狗、餐桌、电视 | 黄绿色 `#91C20D` |

中文字体随程序离线附带，不依赖 Windows 已安装字体。旧自动 / Haar / 移动模式继续使用“设置”中的全局三色，商城固定类别色不随这个旧模式颜色选项变化。

在“回放”选择摄像头和“事件录像”，刷新后播放已结束片段。微信仍沿用原扫码配置：先单独发送“今天事件”（也支持“今日事件”），收到列表后再单独发送“播放第一条”；也可发送“最新事件”。每条消息只发一个指令。网页回放、下载和微信共用同一个完成的 MP4。详情见同包“微信ClawBot-操作步骤.txt”。

## 本次实测与漏检排查

2026-10-19，用户在本机电脑摄像头、YOLOX-S / 0.35 下确认“杯子有橙框和标签，移动时能跟随”。同轮微信“今日事件 → 播放第一条”已确认返回列表和可播放视频；未单独确认本次杯子标签在手机的可读性。

内置 NanoDet 在本次杯子场景漏检，改用商城已有的 YOLOX-S 后通过。若出现有行人框但杯子没框，先核对“当前生效”模型和选中目标；试用 YOLOX-S、保证杯身完整可见并录制新事件，再判断效果。旧录像不会自动补上新框。该实测只覆盖当前电脑、镜头、物品和设置，不代表所有杯子或其他类别都能识别。

## 需要知道的识别边界

- 座椅使用 COCO 的 chair 类别。椅子和凳子合并为一个选项，模型没有独立的凳子类别，可能漏检凳子；桌子使用 dining table 类别，不代表所有桌型。
- 宠物只合并猫与狗，勾选“宠物 + 猫/狗”会自动去重，不代表识别所有宠物。
- 静止的椅子、桌子、瓶子等也可能持续触发录像，直到单次事件上限。可取消该目标或调整镜头；程序不会把“静止”自动当成目标消失。
- 不提供身份识别。光线、遮挡、小目标、相似物品均会影响结果，合成测试和公开样例不能证明家庭场景准确率。
- YOLOX-S 比轻量模型更消耗 CPU。推理或画框超时会保留原画面，摄像头状态会显示提示；不会拿旧框触发新事件，也不会无限积压视频帧。
- 模型在本机运行，不上传摄像头画面；下载仅访问固定官方 HTTPS 模型来源。不能导入任意脚本、PT 文件或自行填入模型网址。

## 保存与恢复

下载模型保存在程序数据目录的 models 子目录，与配置、录像同属持久数据，不放在一次性解包目录。程序退出或重启后仍保留。更新版本前先退出并备份自己的数据目录；不要把含账号、日志、录像的数据目录公开上传。

模型文件丢失或损坏会显示不可用，请重新下载并应用；不会悄悄改回“只识别人”。需要恢复旧行为时，在“设置 → 事件检测 → 模式”选择自动、Haar 或移动侦测并保存。切换会结束当前事件并保留录像。
