MiniNVR2 微信同一 Wi-Fi 预览操作步骤
适用版本：Windows 64 位 v2.4.0
包内文件名：微信局域网预览-操作步骤.txt

准备好再开始

手机和运行 MiniNVR2 的电脑连接同一个可信 Wi-Fi。电脑保持开机，MiniNVR2 持续运行，不要让电脑进入休眠。

这项功能用来查看指定摄像头的当前画面，不需要先录制事件，也不会打开完整管理页面。

需要手机使用移动网络或其他 Wi-Fi 时，请改看同目录“微信远程预览-操作步骤.txt”。使用本篇同一 Wi-Fi 方式前，请先取消“微信优先使用远程预览链接”并保存。

1. 启动并确认电脑画面

   完整解压 MiniNVR2-v2.4.0-windows-x64.zip，双击 MiniNVR2.exe。
   电脑浏览器没有自动打开时，在这台电脑上访问 http://localhost:8800 。
   在“预览”页面确认自己要查看的摄像头有正常画面。

2. 启用微信并扫码

   打开“设置”，找到“微信 ClawBot”。勾选“启用”和“已登录时自动接消息”，点击“保存设置”。
   点击“扫码登录”，用自己的手机微信扫描二维码，并在手机确认。
   电脑应显示“已登录，正在接收微信消息”。已经是这个状态时，无需重复扫码。

3. 开启局域网预览

   先取消“微信优先使用远程预览链接”。
   在同一张设置卡片中找到“微信局域网预览（同一 Wi-Fi）”。
   勾选“启用局域网预览”。
   “本机 Wi-Fi IPv4”先留空，让程序自动选择。
   端口保留 8803。
   点击“保存设置”，确认预览状态显示“已开启”。

4. 在手机微信发指令

   打开“微信 ClawBot”聊天，每条消息只发送一个指令。
   查看第一台摄像头时，单独发送：

   预览1号

   按名称查看时，发送“预览 摄像头名称”，把“摄像头名称”换成自己的设备名称，中间留一个空格。
   例如设备名称叫“农场”，就发送：

   预览 农场

5. 点击链接看画面

   点击机器人回复中的“打开实时预览”。页面约每秒更新一次，没有声音。
   每个链接只对应一台摄像头，有效期10分钟，请勿转发给其他人。
   切到后台时暂停刷新，回到页面后恢复。

6. 需要时重新取链接

   链接到期、程序重启或更新后，重新向机器人发送预览指令，点击新链接。
   关闭局域网预览、退出微信登录、更换登录身份或停用摄像头，也会使旧链接失效。

打不开时按顺序检查

一、机器人提示“尚未开启”
   回到电脑设置，勾选“启用局域网预览”并保存，查看预览状态有没有报错。

二、机器人没有回复
   确认电脑微信状态为“已登录，正在接收微信消息”，查看设置页的错误提示。
   只有显示登录过期时，才需要重新扫码。程序重启后请重新发一次预览指令。

三、电脑能打开，手机打不开
   确认手机和电脑连接同一个 Wi-Fi，手机没有切到移动数据。
   访客网络、路由器的设备隔离或客户端隔离，可能阻止手机连接电脑。

四、自动选择的地址不是当前 Wi-Fi 地址
   在 Windows“设置 → 网络和 Internet → Wi-Fi → 当前网络属性”中，找到这台电脑的 IPv4 地址。
   把它填入 MiniNVR2 的“本机 Wi-Fi IPv4”，保存后重新向机器人请求链接。
   不要填写手机或其他电脑的地址。VPN 和多网卡可能影响自动选择。

五、仍然无法连接
   检查 Windows 防火墙是否允许 MiniNVR2 在专用网络接收连接。
   不要关闭整个防火墙。程序不会自动修改防火墙规则。

六、提示链接无效或画面中断
   链接过期、程序重启或设置改变后，回到微信重新发指令取新链接。
   刷新网页后链接无效时，可回到微信点击原始链接；原始链接也过期时再取新链接。
   如果显示摄像头离线，先在电脑“预览”页检查摄像头。手机页面不会拿旧图当作当前画面。

实测范围

历史验收（v2.2.3）：2026-10-19，用户通过真实微信取得链接，并确认手机画面持续更新，未修改防火墙。
本次仅覆盖一台电脑、一个扫码账号、一部手机和当时网络，未独立核验设备型号或实际场景，不代表真实农场性能或所有网络、设备均兼容。

v2.4.0 保留局域网预览逻辑并通过本机模拟预览检查，本轮没有重新进行同一 Wi-Fi 的手机预览实测。v2.3.0 历史微信内点击验收使用移动网络与合成动画，详见“微信远程预览-操作步骤.txt”，不作为本版同一 Wi-Fi 或手机外网预览的新增实测。

查看已录事件是另一个功能，操作见同目录“微信ClawBot-操作步骤.txt”。2026-10-19，用户在 v2.4.0 最终修复版中新录制事件，确认人物框能跟随，电脑与微信视频均能播放；这不能代替手机实时预览验收。
