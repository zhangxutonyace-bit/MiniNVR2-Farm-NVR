# 微信查看指定摄像头的当前画面

适用于 v2.2.3。手机和运行 MiniNVR2 的电脑须连接同一个可信 Wi-Fi；电脑保持开机，程序持续运行。

1. 在电脑的“预览”页确认摄像头已有正常画面。
2. 在“设置 → 微信 ClawBot”启用微信、扫码登录，并确认正在接收消息。已经登录的用户无需重复扫码。
3. 在同一设置卡片的“微信局域网预览（同一 Wi-Fi）”勾选“启用局域网预览”。IPv4 地址先留空自动选择，端口保留 `8803`，点击“保存设置”。状态应显示“已开启”及电脑的局域网地址。
4. 在手机微信 ClawBot 聊天中，**单独发送 `预览1号`**，或发送 `预览 农场`（把“农场”替换为摄像头名称）。只有一路摄像头时，也可以只发送 `预览`。
5. 点击机器人返回的链接，查看该摄像头的当前画面。页面约每秒刷新一次，无声音；切换到后台会暂停，回到页面恢复。

每个链接只用于一台摄像头，有效期10分钟，请勿转发。到期后重新发送预览指令获取新链接。关闭局域网预览、退出微信登录、更换登录身份或停用摄像头后，旧链接失效。链接不提供管理或录像下载权限。

## 打不开时

- **机器人提示尚未开启**：回到电脑设置勾选启用，并保存；检查预览状态是否报错。
- **地址不是当前 Wi-Fi 地址**：多网卡或 VPN 可能影响自动选择。在 Windows“设置 → 网络和 Internet → Wi-Fi → 当前网络属性”查看电脑的 IPv4 地址，把该地址填入程序的“本机 Wi-Fi IPv4”后保存，再向机器人请求新链接。不能填写手机或其他电脑的地址。
- **电脑能打开、手机打不开**：确认两台设备连接同一个 Wi-Fi，手机没有改用移动数据，且不是启用了设备隔离的访客网络。检查 Windows 防火墙是否允许此程序在专用网络接收连接；不要关闭整个防火墙。程序不会自动修改防火墙规则。
- **显示摄像头离线或画面中断**：先检查电脑“预览”中的设备状态。手机页不会用旧图冒充当前画面。
- **刷新网页后提示链接无效**：回到微信点击原始链接；原始链接过期时重新发预览指令。为减少密钥残留，页面打开后会从地址栏移除链接密钥。

此入口仅供同一局域网使用。它与微信直接接收事件录像是两个独立入口：接收录像需有已完成的事件文件，查看当前画面无需提前录制事件。
