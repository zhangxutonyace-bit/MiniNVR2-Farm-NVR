## 本版更新

- **实时预览识别框：** 默认开启“实时显示识别框和标签”，直接查看当前生效算法识别出的目标；短暂漏检结合当前画面连续跟随，目标离开或结果过期时清框。
- **按类别着色并显示中文标签：** 与商城新事件录像使用相同的红、橙、深蓝、黄绿四色和“行人”“杯子”“猫”“狗”等标签。颜色稳定区分类别，不代表危险等级或身份。
- **独立切换原画面：** 取消预览勾选可对比原画面，只影响当前电脑页面；“事件录像显示目标框”仍单独控制录像，抽帧保持原画面。
- **共享识别与流畅度处理：** 多个观看窗口共用同一路模型和结果，按需刷新；处理跟不上时优先更新原画面并提示，避免持续积压视频帧。
- **切换与停用修补：** 摄像头关闭检测、重连或切换模型时清理不匹配的预览结果，微信预览也检查当前模型与检测状态；修补 Windows 临时配置保存冲突。
- **保留已有功能：** RTSP、电脑内置 / USB 摄像头、算法商城、事件录像、回放、微信事件查询及原有局域网 / 外网预览入口继续沿用。

## 实时预览彩框六步上手

1. 启动程序，在“摄像头”添加并启用 RTSP 摄像头，或刷新设备列表、选择电脑内置 / USB 摄像头并添加启用；到“预览”确认画面在线。
2. 打开“算法商城”，选择已就绪模型。内置 NanoDet 无需下载；YOLOX Nano / YOLOX-S 需先点击“下载”并等待就绪。
3. 勾选需要识别的目标，取消不需要的目标；杯子可先尝试 **YOLOX-S / 0.35**。首次先用一路摄像头，该模型比轻量模型更消耗 CPU。
4. 点击 **“应用模型和选中目标”**，核对“当前生效”。仅下载、勾选还不会生效；应用时会结束当前事件并保留片段。
5. 确认 **“设置 → 事件检测 → 启用检测”** 和该路摄像头 **“参与检测”** 都已打开。
6. 回到“预览”，保持默认勾选的 **“实时显示识别框和标签”**。让选中目标进入镜头、缓慢左右移动，观察彩框与标签跟随；取消勾选可对比原画面。

需要看录像时，等目标离开、事件结束后，到“回放 → 事件录像”刷新。新事件是否写入框由“设置 → 录像 → 事件录像显示目标框”控制，旧录像不会补框。

## 微信查询与预览

启用“设置 → 微信 ClawBot”的“启用”和“已登录时自动接消息”，保存后点击“扫码登录”，用本人微信扫码并确认。电脑需持续开机、联网并运行程序。

- **查事件录像：** 单独发送“今天事件”或“今日事件”，收到列表后再单独发送“播放第一条”；也可发送“最新事件”。每条消息只发一个指令，事件录像查询无需配置 NetBird。
- **看当前画面：** 先按原步骤开启局域网或远程预览，在微信单独发送“预览1号”或“预览 摄像头名称”，点击“打开实时预览”。既有链接读取同一路彩框画面，仍约每秒刷新一次；电脑页面的彩框开关不改变微信页面。链接10分钟有效，功能不会自动开启网络入口。

同一 Wi-Fi 可使用局域网预览；手机使用移动网络或其他 Wi-Fi 时，需先在电脑安装、登录并授权 NetBird，再在 MiniNVR2 阅读转发说明并手动开启远程预览。手机无需另装 VPN 应用；NetBird 服务商可处理转发画面，免费档及限制由服务商决定。

**V3.1 新增彩框在手机上的实际效果尚未由用户确认。** 本版电脑预览实测与旧版手机验收分别记录。

## 本次实测与范围

2026-10-20，用户在本机电脑摄像头、**YOLOX-S / 0.35**、杯子 / 瓶子选项下，移动杯子后确认：**“彩框和标签能跟随，画面流畅”**。这覆盖当次电脑、摄像头、物品、设置与操作，不代表其他场景的准确率或性能。

完整离线回归 **410/410 项通过**。最终同一 Windows EXE 的公开样例检查覆盖同一路画面的一 / 三个观看窗口：8 fps 输入下稳态输出约 **7.95–7.98 fps**，测得类别框覆盖率100%，无帧序倒退；默认0.5秒检测间隔、没有事件录像任务时也通过预览检查。原始截图和抽帧保持无框，完成事件与网页播放的文件一致。公开样例与离线检查不代替真实家庭场景精度、真实手机收件或长期运行验收。

需要了解的边界：

- 实时类别框需要应用商城模型，并启用全局及该路检测。旧自动 / Haar / 移动模式显示原画面。
- 商城保留14个勾选项、13个 COCO 类别；座椅暂不区分椅子和凳子，宠物只包含猫狗，桌子对应餐桌类别。
- 模型在本机 CPU 运行。遮挡、强逆光、小目标、模型能力及电脑负载都可能影响识别和跟随；处理超时可能暂时缺框。
- 静止的选中物品也可能持续触发录像；预览刷新不会改变原有连续命中、离开停录等事件条件。
- 其他模型 / 目标、其他电脑、多路长期运行、V3.1 手机彩框和手机外网预览仍需分别验证。
