## 本版更新

- **电脑摄像头接入：** 在“摄像头”页刷新设备列表，选择内置或 USB 摄像头并添加启用，到“预览”即可查看。预览、检测、录像共享一次设备采集，不采集麦克风。停用、删除或退出程序会释放镜头。
- **沿用原有事件流程：** 事件触发、连续命中和离开后停录仍使用现有算法及设置；录像继续进入原有回放、下载和微信查询流程。
- **事件录像显示目标框：** 开关默认打开，红色 `#F51616`、橙色 `#E86D08`、深蓝色 `#0931C0` 可选，颜色只便于适应背景。保存后从下一次事件生效，旧录像不会补框。
- **人物框连续跟随：** 自动 / Haar 模式使用随程序附带的约3.8 MB NanoDet 人物模型定位，再以图像跟踪保持连续移动，修复旧方案容易跳到背景、尺度变化残留双框等问题。该模型只负责画框，不改变事件触发和停录算法；无需联网或额外下载模型。移动侦测模式仍只画移动区域。
- **中文播放指令：** 收到事件列表后，可单独发送“播放第一条”，也兼容“播放第1条”“播放第一段”“播放第1条事件”。取片依据本人最近查询的列表，每条消息只发送一个指令。

## 快速使用

1. 完整解压后运行程序。电脑浏览器未自动打开时，访问 `http://localhost:8800`。
2. 在“摄像头”添加自有 RTSP 摄像头，或在“电脑摄像头”刷新列表、选择设备并添加启用；先到“预览”确认画面正常。
3. 在“设置”启用人形检测，并确认该路摄像头的“识别人”开关打开。“录像 → 事件录像显示目标框”默认开启，可按背景选择颜色并保存。
4. 进入镜头并走动，再离开，等事件结束后到“回放”选择“事件录像”并刷新。
5. 需要微信查看时，在“设置 → 微信 ClawBot”勾选“启用”“已登录时自动接消息”，保存后用本人微信扫码并确认。
6. 在微信单独发送 **“今天事件”**，收到列表后再单独发送 **“播放第一条”**；也可单独发送 **“最新事件”**。收到视频后点击播放。电脑需保持开机、联网且程序持续运行。

查看已保存事件无需 NetBird，也无需先配置实时预览。详细说明见 [电脑摄像头步骤](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/blob/v2.4.0/docs/LOCAL_CAMERA_QUICK_START.md)和[微信步骤](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/blob/v2.4.0/docs/WECHAT_QUICK_START.txt)。

## 微信实时预览

已有预览功能继续保留：

- **同一 Wi-Fi：** 启用微信并扫码；取消“微信优先使用远程预览链接”，启用局域网预览并保存。在微信单独发送 **“预览1号”** 或 **“预览 摄像头名称”**，点击 **“打开实时预览”**。[详细步骤](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/blob/v2.4.0/docs/LAN_PREVIEW.md)。
- **移动网络或其他 Wi-Fi：** 只在电脑安装、登录 NetBird，在控制台为仅含本机的组授权 Peer Expose；在 MiniNVR2 保存远程优先设置，阅读转发说明并手动开启远程预览。手机发同样的预览指令并点击 **“打开实时预览”**，无需额外 VPN 应用。[完整配置](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/blob/v2.4.0/docs/REMOTE_PREVIEW.md)。

实时预览约每秒更新、无声音，单路链接10分钟有效，请勿转发。电脑或程序重启后需重新取得链接，外网预览还需在电脑手动重新开启。NetBird 代理服务商能够处理经其转发的画面，免费档资格和限制由服务商决定，接受后再启用。
