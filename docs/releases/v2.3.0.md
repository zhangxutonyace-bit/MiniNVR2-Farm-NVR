## 微信外网预览：首次六步配置

1. 在电脑“预览”页确认摄像头画面正常；在“设置 → 微信 ClawBot”启用微信、扫码登录，确认正在接收消息。不需要先录制事件。
2. 从 [NetBird 官网](https://netbird.io/download) 在电脑安装 Windows 客户端，由你注册或登录 NetBird 账号，确认显示 **Connected**。手机不需要安装。
3. 用同一个 NetBird 账号登录[网页控制台](https://app.netbird.io/)。在 **Access Control → Groups** 建立仅包含本机的组；进入 **Settings → Clients → Peer Expose**，开启 **Enable Peer Expose**，仅允许该组并保存。
4. 在 MiniNVR2“设置 → 微信远程预览”勾选 **“微信优先使用远程预览链接”**，点击 **“保存设置”**。
5. 阅读转发说明，点击 **“同意转发并开启远程预览”**，等待连接就绪。
6. 手机关闭 Wi-Fi、使用移动数据，在微信单独发送 **`预览1号`** 或 **`预览 摄像头名称`**，点击回复中的 **“打开实时预览”**，确认画面持续更新。

电脑须持续开机、联网且不休眠，程序重启后要手动重新开启远程预览。页面约每秒刷新一次，无声音；每条链接只对应一台摄像头，10分钟有效，请勿转发。到期重新发送指令并打开最新回复。不使用时点击“停止远程预览”。完整排查见[远程预览操作步骤](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/blob/v2.3.0/docs/REMOTE_PREVIEW.md)。

仍可使用同一 Wi-Fi 预览：先取消远程优先，再启用局域网预览。查询事件录像继续使用 `最新事件`、`今天事件`、`播放第1条` 等指令，无需先安装 NetBird 或配置远程预览。
