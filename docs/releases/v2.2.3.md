## 微信查看当前画面

1. 手机和电脑连接同一个可信 Wi-Fi，在电脑“预览”页确认摄像头画面正常。
2. 打开“设置 → 微信 ClawBot”，启用微信并扫码登录，确认正在接收微信消息。
3. 勾选“启用局域网预览”，“本机 Wi-Fi IPv4”先留空自动选择，端口保留 `8803`，保存并确认状态为“已开启”。
4. 在微信 ClawBot 聊天中单独发送 `预览1号`，或 `预览 摄像头名称`，点击返回的链接。

页面约每秒刷新一次，无声音；单路链接10分钟过期，请勿转发。到期、程序重启或更新后，重新发送指令取新链接。此入口只供同一局域网查看当前画面。

打不开时，检查同一 Wi-Fi、手机移动数据及访客网络的设备隔离；自动地址不对时，填入这台电脑当前 Wi-Fi 的 IPv4 后保存并取新链接。检查防火墙对程序的专用网络许可，不要关闭整个防火墙。完整说明见[Windows 使用说明](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/blob/v2.2.3/docs/WINDOWS_DOWNLOAD.md)及[局域网预览步骤](https://github.com/zhangxutonyace-bit/MiniNVR2-Farm-NVR/blob/v2.2.3/docs/LAN_PREVIEW.md)。

原有事件列表、日期/摄像头筛选、本人15分钟分页和事件录像回传继续可用。每条消息只发一个指令，例如先发 `今天事件`，收到列表后再发 `播放第1条`；`最新事件` 可取今天最近一段已完成录像。
