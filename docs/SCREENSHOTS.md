# 产品实际界面截图

以下5张图片由用户于2026-10-19提供，展示 MiniNVR2 的实际使用界面。原图未经修改，点击图片可查看大图。截图展示界面与一次使用画面，具体运行效果取决于设备、网络和现场环境。

## 1. 实时预览

查看摄像头当前画面、设备名称和在线帧率。

[![实时预览](screenshots/01-live-preview.png)](screenshots/01-live-preview.png)

## 2. 摄像头管理

网段扫描、手工添加RTSP摄像头、查看在线状态，以及启用或停用检测。图中添加框内的账号密码属于程序公开的示例占位符；已配置设备的认证部分显示为星号。

[![摄像头管理](screenshots/02-camera-management.png)](screenshots/02-camera-management.png)

## 3. 录像回放界面

按摄像头和录像类型筛选，并从列表选择录像播放。此截图显示暂无已完成录像，用于展示筛选入口和播放器布局。

[![录像回放界面](screenshots/03-recordings.png)](screenshots/03-recordings.png)

## 4. 设置界面

截图覆盖部分设置区域，包括访问口令、取流参数、检测、录像保留、邮件和微信 ClawBot 登录选项。微信局域网预览的完整配置步骤见 [操作说明](LAN_PREVIEW.md)。

[![设置界面](screenshots/04-settings.png)](screenshots/04-settings.png)

## 5. 检测画面示例

画面中的红框展示目标标注。单张截图不能衡量检测准确率，实际效果需结合光线、距离、遮挡和现场运动情况验证。

[![带红框标注的检测画面](screenshots/05-detection-example.png)](screenshots/05-detection-example.png)

以上截图来自 v2.2.3，保留原始使用画面，不代表 v2.4.0 新增的电脑摄像头入口与人物框连续跟随界面。
