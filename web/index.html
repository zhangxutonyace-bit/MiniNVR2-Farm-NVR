取流

事件检测

各路检测依次执行；增加摄像头仍会增加取流与整体资源消耗。 事件检测触发录像；抽帧按设定间隔单独保存。旧模式保持原行为，多目标需到算法商城应用。切换模式会结束当前事件并保留录像。

录像

默认打开，下次事件开始生效。商城模式按类别固定颜色，附紧凑中文标签，只有标签背景填色；旧模式沿用上方全局三色。打开后按预览分辨率（通常宽 480 像素）重新编码，RTSP 录像清晰度可能降低，CPU 占用增加；关闭后沿用原录像方式。目标区域仅描边、不填充，颜色不表示危险等级。移动侦测框表示移动区域，不能视为已确认的人；静止目标可能无框。处理失败时保留原画面，并在摄像头状态提示。

首次配置与使用步骤
  1. 在电脑上从 NetBird 官网安装 Windows 客户端，由你注册或登录自己的账号并连接。手机只用微信。
  2. 在 NetBird 控制台 Settings → Clients 开启 Peer Expose，按需要授权本机所在组。不要映射录像机管理端口或整个局域网。
  3. 启用微信 ClawBot 并扫码登录，勾选上面的远程选项，保存后点击“同意转发并开启远程预览”。等待状态显示连接就绪。
  4. 在微信单独发送“预览1号”或“预览 摄像头名称”，打开新回复的 HTTPS 链接。链接10分钟有效，约每秒刷新一帧，请勿转发。

免费档及代理测试版的限制由 NetBird 决定，不保证永久免费或所有网络可达。电脑需保持运行、联网；首次应关闭手机 Wi-Fi，用移动网络验证。选择远程模式但连接未就绪时会提示错误；如需恢复同 Wi-Fi 预览，取消远程选项并保存。
